# Changelog

## 1.0.0

### Added
- HUD overlay for live FPS and tick timing diagnostics
- Dashboard with overview, frames, ticks, status, settings, and compatibility tabs
- Render-side particle and distance limits
- Performance presets for Potato, Balanced, and Quality
- Local CSV profiling export for the last recorded server ticks
- Compatibility guards for Lithium, FerriteCore, Sodium, and Iris

### Improved
- Adaptive performance throttling for unstable frame times
- Alert suppression and rate limiting for lag reports
- Config-safe defaults for low-end systems

### Notes
- Experimental logic mixins remain disabled by default
- The mod is designed for Minecraft 26.3 and Fabric Loader 0.19.5+
